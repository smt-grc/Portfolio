## Projects

### [GRC Python Bootcamp](grc-python-bootcamp/)

A hands-on study plan that teaches Python by building real Governance, Risk &
Compliance (GRC) automation tools. Ten progressive lessons, each ending in a
working tool you can run on your own data — from a password-policy checker and
access-review helper up to a CVE scanner, risk analytics, and a continuous
compliance monitor. See [`grc-python-bootcamp/README.md`](grc-python-bootcamp/README.md)
to get started.
